# Knowledge base — attribution

These basketball concept, strategy, and scouting documents were scraped and
curated by **Blake Wood** for his [BenchGPT](https://github.com/blocke123a/BenchGPT)
project (a RAG basketball assistant). They're reused here, with thanks, to give
the matchup assistant grounded answers about basketball concepts and the metrics
this model uses (BPM, Four Factors, ratings, etc.).

Original sources include Basketball-Reference glossaries, Hooper University,
82games, and others (see each document's context). The live matchup predictions
are grounded separately on the model's own numbers.
